# Velora-2

Лендинг Velora, сверстанный 1:1 по макету Figma
([Concept 1](https://www.figma.com/design/1Ebb2p67jrZHNAmbTDkn0O/Velora?node-id=635-4166)).

Чистые HTML + CSS, без сборки. Макет рассчитан на ширину 1440px.

## Структура

```
index.html          разметка страницы
css/styles.css      стили (все отступы, цвета, размеры шрифтов из Figma)
js/main.js          лоудер и анимации появления
assets/icons/       логотипы и иконки (SVG)
assets/images/      логотипы партнёров (PNG)
assets/svg/         декоративные фоны: свечения, лучи, линии (SVG)
assets/loader/      исходники лоудера из Figma (логотип, лучи, веер)
```

Шрифты (Manrope, Newsreader, Inter, Instrument Sans) подключаются из Google Fonts.

## Анимации

- Лоудер по раскадровке Figma (Loading Animation): знак собирается по штрихам,
  счётчик идёт до 100%, из знака вырастают лучи, затем они складываются в веер
  и появляется надпись Velora. Лоудер ждёт полной загрузки страницы.
- После лоудера появляются элементы интерфейса (кнопки, меню, логотипы,
  карточки, окно продукта); заголовки и тексты не анимируются.
- Ховеры: кнопки слегка увеличиваются, стрелка в «Book a demo» уезжает вправо;
  карточки с цифрами подсвечиваются градиентом только при наведении.
- При включённой в системе настройке «уменьшить движение» лоудер и анимации
  отключаются.

## Запуск

Маски свечений в первом экране грузятся как CSS `mask-image`, поэтому страницу
нужно открывать через локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
